# Reference

> IDs like `R-6`, `S-4`, `INV-2` and `A-9` are numbered requirements. Each is enforced by
> a named test — see [BEHAVIOR.md](BEHAVIOR.md), which is generated from the test suite.
> You never need them to use the tool; they're there so every claim is traceable to
> something that's actually checked.
